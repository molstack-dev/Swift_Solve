SwiftSolve - versión estática

Este sitio está hecho con HTML, CSS y JavaScript nativos. No requiere Node.js, React, servidor backend ni inicio de sesión.

Para probarlo: abre index.html en un navegador.
Para publicarlo: sube todo el contenido de esta carpeta a un hosting estático (GitHub Pages, Netlify, Cloudflare Pages o hosting tradicional). Mantén la carpeta assets junto a los HTML.

Páginas: index.html, servicios.html, metodologia.html, contactos.html, estructura.html, mision-vision.html, valores.html, identidad-visual.html.
